# mtimer

Марафон-таймер для OBS. Час поповнюється автоматично від донатів на банку Monobank і від підписок на Twitch (окремий тариф для Tier 1, 2 і 3).

| Файл | Що це |
| --- | --- |
| `worker.js` | Cloudflare Worker: зберігає налаштування, приймає вебхуки Monobank і Twitch, віддає стан таймера |
| `admin.html` | Адмінка. Відкривається локально в браузері |
| `timer.html` | Сам таймер. Додається в OBS як Browser Source |
| `wrangler.toml` | Конфіг для деплою через Wrangler (потрібен лише для варіанта Б у кроці 2) |

## Що знадобиться

- Акаунт Cloudflare (вистачає безкоштовного плану).
- Особистий токен Monobank: <https://api.monobank.ua/>.
- Акаунт Twitch каналу з увімкненою двофакторною автентифікацією (без неї Twitch не дає створювати застосунки).

## Крок 1. Придумайте токен адміністратора

Це довільний довгий рядок, яким адмінка підтверджує себе перед воркером. Впишіть однакове значення у двох місцях:

- `worker.js`, рядок `const ADMIN_TOKEN = 'change-me';`
- `admin.html`, рядок `const ADMIN_TOKEN = 'change-me';`

Поки у воркері стоїть `change-me`, він відхиляє всі запити адмінки.

Через адмінку видно токен Monobank і Client Secret Twitch, тому не публікуйте `admin.html` зі своїм токеном і не комітьте його в публічний репозиторій.

## Крок 2. Розгорніть воркер

### Варіант А. Через дашборд Cloudflare

1. **Storage & Databases → KV → Create** — створіть namespace з будь-якою назвою, наприклад `mtimer`. У ньому зберігаються налаштування.
2. **Storage & Databases → D1 → Create** — створіть базу з будь-якою назвою, наприклад `mtimer`. У ній зберігається стан таймера і журнал подій. Таблиці воркер створить сам.
3. **Workers & Pages → Create → Worker** — створіть воркер, наприклад `marathon-timer`.
4. Відкрийте редактор коду воркера, замініть увесь вміст на вміст `worker.js` і натисніть **Deploy**.
5. У воркері відкрийте **Settings → Bindings → Add** і додайте дві прив'язки:
   - **KV namespace** — Variable name: `TIMER_KV`, namespace з пункту 1;
   - **D1 database** — Variable name: `TIMER_DB`, база з пункту 2.

### Варіант Б. Через Wrangler

```sh
npx wrangler login
npx wrangler kv namespace create TIMER_KV
npx wrangler d1 create mtimer
```

Команди повернуть `id` і `database_id`. Вставте їх у `wrangler.toml` замість `REPLACE_WITH_KV_NAMESPACE_ID` і `REPLACE_WITH_D1_DATABASE_ID`, потім:

```sh
npx wrangler deploy
```

### Перевірка

Запам'ятайте адресу воркера, вона має вигляд `https://marathon-timer.<ваш-субдомен>.workers.dev`. Відкрийте в браузері `<адреса>/api/timer`. Має повернутись JSON на кшталт:

```json
{"running":false,"endsAt":0,"remainingMs":0,"now":1791746987697}
```

## Крок 3. Впишіть адресу воркера

У `admin.html` і в `timer.html` замініть значення `WORKER_URL` на адресу воркера, без `/` в кінці:

```js
const WORKER_URL = 'https://marathon-timer.<ваш-субдомен>.workers.dev';
```

## Крок 4. Відкрийте адмінку

Відкрийте `admin.html` подвійним кліком. Якщо адреса і токен правильні, поля заповняться значеннями за замовчуванням.

Кнопки вгорі:

- **Pull** — завантажити налаштування з воркера у форму.
- **Push** — зберегти форму у воркер. Зміни в полях не діють, доки не натиснуто Push.

## Крок 5. Задайте тарифи

У блоці «Тарифи»:

- **Кожні N грн додають M секунд** — донат рахується пропорційно сумі. За замовчуванням 10 грн = 60 секунд, тобто 50 грн додають 5 хвилин.
- **Мін. донат** — менші суми ігноруються.
- **Twitch Tier 1 / 2 / 3** — скільки секунд додає одна підписка кожного рівня. Prime-підписка рахується як Tier 1.

Натисніть **Push**.

## Крок 6. Підключіть Monobank

1. Вставте токен у поле «Токен».
2. Натисніть **Завантажити рахунки**.
3. У списку виберіть банку, на яку збираєте донати.
4. Натисніть **Встановити вебхук**.

Зараховуються лише надходження на вибрану банку. Інші рахунки і витрати на таймер не впливають.

Monobank дозволяє один вебхук на токен. Якщо цей токен уже використовує інший сервіс, його вебхук буде замінено.

## Крок 7. Підключіть Twitch

1. Відкрийте <https://dev.twitch.tv/console/apps> і натисніть **Register Your Application**.
   - **Name** — будь-яка унікальна назва.
   - **OAuth Redirect URLs** — адреса з рядка «OAuth Redirect URL» в адмінці, тобто `<адреса воркера>/twitch/callback`.
   - **Category** — будь-яка, наприклад Broadcaster Suite.
   - **Client Type** — Confidential.
2. Відкрийте створений застосунок, скопіюйте **Client ID**, натисніть **New Secret** і скопіюйте **Client Secret**.
3. Вставте обидва значення в адмінку.
4. Натисніть **Авторизувати канал**. У новій вкладці увійдіть акаунтом каналу і підтвердіть доступ.
5. Вкладка покаже результат: три рядки зі статусом `webhook_callback_verification_pending`. Це нормально.
6. Поверніться в адмінку і натисніть **Статус підписок**. Усі три мають бути `enabled`:
   - `channel.subscribe` — нові підписки;
   - `channel.subscription.gift` — подаровані підписки (кількість × тариф рівня);
   - `channel.subscription.message` — продовження підписок.

Якщо статус інший, натисніть **Перепідписати вебхуки** і перевірте ще раз.

## Крок 8. Запустіть таймер

1. У блоці «Таймер» введіть стартовий час і натисніть **Встановити час**.
2. Натисніть **Старт**.

Далі під час стріму:

- **Пауза / Старт** — зупинити і продовжити відлік. Донати на паузі теж зараховуються.
- **+ Додати / − Відняти** — ручна корекція у хвилинах.
- **Оновити** — перечитати стан і журнал подій.

«Встановити час» замінює поточний залишок, стан старт/пауза при цьому не змінюється. Для дрібних виправлень посеред марафону користуйтесь «Додати» і «Відняти».

## Крок 9. Додайте таймер в OBS

1. **Sources → + → Browser**.
2. Увімкніть **Local file** і виберіть `timer.html`.
3. Задайте розмір, наприклад 800 × 200. Розмір цифр залежить від ширини джерела.

Фон прозорий. Коли час поповнюється, над таймером спливає «+5:00».

Вигляд змінюється на початку `timer.html`:

```css
:root {
  --color: #ffffff;                 /* колір цифр */
  --accent: #7dffb0;                /* колір спливаючого «+5:00» */
  --outline: rgba(0, 0, 0, .85);    /* обводка */
  --size: 22vw;                     /* розмір цифр відносно ширини джерела */
}
```

Там само `POLL_MS` — як часто таймер опитує воркер (за замовчуванням раз на 2 секунди).

## Перевірка перед стрімом

1. Киньте на банку суму, не меншу за мінімальний донат.
2. Натисніть **Оновити** в адмінці: у журналі має з'явитись рядок «Monobank», а час — зрости.
3. Таймер в OBS покаже поповнення за кілька секунд після того, як Monobank надішле вебхук.

## Обмеження

- **Затримка показу.** Таймер в OBS опитує воркер раз на 2 секунди, тож поповнення видно майже одразу після вебхука. Сам вебхук Monobank і Twitch надсилають за кілька секунд після події.
- **Безкоштовний план Cloudflare.** Ліміт — 100 тис. запитів до воркера на добу. Одне джерело в OBS з опитуванням раз на 2 секунди дає близько 43 тис. Якщо таймер відкрито в кількох джерелах або сценах одночасно, збільште `POLL_MS`.
- **Зміна тарифів.** Налаштування зберігаються в KV і розходяться по мережі Cloudflare до хвилини, тому новий тариф може почати діяти не миттєво.
- **Продовження підписок.** Twitch повідомляє про продовження лише тоді, коли глядач публікує повідомлення про це в чаті.
- **Валюта.** Тариф рахується у валюті банки. Для банки в доларах чи євро «грн» у тарифі означає одиницю цієї валюти.

## Якщо щось не працює

| Симптом | Причина |
| --- | --- |
| Адмінка: «Задайте власний ADMIN_TOKEN у worker.js» | У воркері лишився `change-me`, або змінений код не задеплоєно |
| Адмінка: «Невірний токен адміністратора» | Токени в `admin.html` і `worker.js` різні |
| Адмінка: `Failed to fetch` | Неправильний `WORKER_URL`, або до воркера не прив'язано `TIMER_KV` |
| Адмінка: «До воркера не прив'язано базу D1» | Немає прив'язки `TIMER_DB` (крок 2) |
| Таймер в OBS показує `--:--:--` | Неправильний `WORKER_URL` у `timer.html` |
| Донати не додають час | Не вибрано банку, не натиснуто Push після вибору, сума менша за мінімальну, або вебхук Monobank вказує на інший сервіс («Завантажити рахунки» покаже поточний) |
| Twitch: `redirect_mismatch` | Redirect URL у застосунку Twitch не збігається з тим, що показує адмінка |
| Підписки Twitch у статусі `authorization_revoked` | Доступ відкликано. Натисніть «Авторизувати канал» ще раз |
| Monobank: «Too many requests» | «Завантажити рахунки» можна натискати не частіше ніж раз на хвилину |

## Ендпоінти воркера

| Метод і шлях | Доступ | Призначення |
| --- | --- | --- |
| `GET /api/timer` | публічний | Стан таймера для `timer.html` |
| `GET`, `PUT /api/settings` | токен | Читання і запис налаштувань |
| `GET /api/status` | токен | Стан таймера і журнал подій |
| `POST /api/timer` | токен | Дії: `set`, `add`, `pause`, `resume` |
| `GET /api/mono/accounts` | токен | Список банок і рахунків |
| `POST /api/mono/webhook` | токен | Реєстрація вебхука в Monobank |
| `GET /api/twitch/auth-url` | токен | Посилання для авторизації каналу |
| `POST /api/twitch/subscribe` | токен | Створення підписок EventSub |
| `GET /api/twitch/status` | токен | Статус підписок EventSub |
| `GET /twitch/callback` | OAuth state | Повернення з авторизації Twitch |
| `/hook/mono/<secret>` | секрет у шляху | Вебхук Monobank |
| `POST /hook/twitch` | підпис HMAC | Вебхук Twitch |

Запити з токеном передають заголовок `Authorization: Bearer <ADMIN_TOKEN>`.
